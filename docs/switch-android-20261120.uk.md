# Перемикання Android, перенесення даних і вибіркові копії (2026-11-20)

На телефоні одночасно живе один Android: один super і одна data, переразмітки немає. Перемкнути систему
означає зберегти поточну, встановити іншу й повернути дані. Рекавері веде цими кроками сторінкою
**Встановлення → Перемкнути Android**.

## Кроки

1. **Зберегти систему й дані.** «Резервна копія → Копія Android»:
   - «Розділи на SD / USB» — вибрані розділи (BOOT, super, dtbo, vbmeta, prism, optics) в одному архіві
     `A22xAndroidBackups/NAME.tar.zst`; з нього система повертається («Резервна копія → Розділи телефону»).
   - «Перенести на інший Android» — зашифрований паролем архів `A22xMigrationBackups/*.tar.gz.enc`:
     дані вибраних програм (з APK), налаштування, контакти, Wi‑Fi, розкладка робочого столу, спільні файли.
     Кнопка «Вміст» відкриває «Що переносити»: **Root і adb** (увімкнений adb, дозволені комп'ютери, правило
     Magisk для adb shell) і **типи спільних файлів** (фото, відео, аудіо, документи, архіви, APK, інші).
2. **Встановити інший Android.** «Android»: прошивка Samsung, ROM із файлу (наприклад LineageOS 20),
   образи GSI; або збережена система з кроку 1.
3. **Форматувати дані для Android.** «Очищення → Дані для Android». Пароль Android потрібен лише тоді,
   коли data зашифрована й має пароль; свіжа або незашифрована data форматується без нього.
4. **Root для нової системи.** Magisk зі сторінки Root; не потрібен, якщо BOOT нової системи має KernelSU
   (H3ckedUI One UI 8.5).
5. **Підготувати перший запуск.** «Файли → SD → A22xMigrationBackups → архів → Нова система: root, adb,
   програми». Рекавері сам монтує свіжу data і кладе в `/data/adb`:
   - правило root для adb shell (KernelSU: його `.allowlist`; Magisk: `/data/adb/magisk` і правило uid 2000);
   - ключі adb старої системи й комп'ютерів, яким дозволено adb цього рекавері;
   - одноразовий сценарій: adb вмикається ще під час старту (post-fs-data), після старту — налаштування,
     встановлення програм (`pm install-create/-write/-commit`) з їхніми даними (новий uid, `restorecon`),
     мережі Wi‑Fi (`cmd wifi add-network`), контакти (dex‑помічник через провайдер контактів нової системи).
6. **Перезапустити в нову систему.** Root з adb і дані повертаються самі; журнал —
   `/data/adb/a22x-migration.log`, виклики заглушки — `/data/adb/a22x-migration.trace`.

## Вибіркові копії файлів

- «Файли»: довге натискання → вибір → «Архів». На сторінці підтвердження перемикач **Файли: усі / фото й
  відео / документи / аудіо / APK / архіви**; теки зберігаються, решта файлів пропускається, вибір записано
  в маніфесті.
- Спільні файли в архіві перенесення — за типами (крок 1).

## Що відкривається без пароля і з паролем

| Система | Шифрування data | Рекавері |
|---|---|---|
| Evolution X 16 | FBE + метадані | відкриває з паролем і без пароля (нативний декрипт) |
| Стоковий One UI 5.1 (A13) | FBE + метадані | відкриває з паролем або графічним ключем |
| One UI 8.5 (H3ckedUI) | немає (у vendor‑fstab fileencryption закоментовано) | читання й запис як звичайної F2FS |
| LineageOS 20 | немає (vendor‑fstab без fileencryption) | читання й запис як звичайної F2FS |
| Свіжа data після форматування | немає | читання й запис, форматування без пароля |

## Ще не перевірено на телефоні

Перший запуск One UI 8.5 після підготовки (перша спроба не дала adb, причину покаже журнал), відновлення
програм, Wi‑Fi і контактів на новій системі, встановлення LineageOS 20 натисканнями в інтерфейсі.
